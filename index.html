02 — Experience

Where the models actually shipped.

Production vision in hospitals and on vehicles, and a research stint teaching a robot to read gauges.

  1. Jun 2026 — Present current

    Machine Learning Engineer, Computer Vision

    RNT Health Insights · On-site

    • Migrated GI endoscopy detection from RT-DETR to RF-DETR to get the accuracy/throughput balance that live decision support during a procedure actually demands.
    • Deployed a fully on-device speech-to-report pipeline (MedASR + Qwen) on a Jetson AGX Orin — clinical documentation automated with patient data never leaving the machine.
    • Engineered embedding-based frame deduplication (DINO / ResNet50 + DBSCAN) to drop redundant endoscopy frames, speeding up training and improving recall on rare anomalies.
    • Optimised multimodal Vision + ASR + LLM pipelines for embedded GPUs to meet hospital latency constraints.
  2. May 2025 — May 2026

    Deep Learning Engineer

    Flux Auto · YC S21 · On-site

    • Integrated 3D LiDAR models (PointNet, PointNet++, Point Transformer) into the autonomous vehicle stack for object detection where camera-only perception failed under variable lighting.
    • Designed a Progressive Morphological Filter ground-removal pipeline to separate true obstacles from road noise — preventing false positives before they reached braking decisions.
    • Deployed low-light image enhancement to hold camera perception together when LiDAR data was sparse or noisy.
  3. Dec 2023 — Feb 2024

    Research Intern

    SMSS Lab · IIT Kanpur · On-site

    • Built computer vision algorithms on a robotic platform to autonomously detect and read physical gauges in hazardous field environments.
    • Fine-tuned a YOLO keypoint + object detection model on a curated field dataset to localise gauge parameters in real time.

03 — Selected work

Projects, and what each one was actually about.

The four builds worth showing — each links straight to the source on GitHub.

Post-training

mathguard

An RLHF-style alignment pipeline for math LLMs: harm refusal lifted from 0% to 88% with a 3.2% GSM8K alignment tax. HarmMathBench plus a DistilBERT reward model blocked all 96 jailbreak attempts against a 1.5B model.

SafetyFine-tuningEvals
Multimodal

Rasengan-XL

PEFT fine-tune of SDXL 1.0 — LoRA, QLoRA and DoRA — fitting a 2.6B-parameter model on a single 16 GB T4 with 4-bit NF4 and gradient checkpointing, so style transfer runs without enterprise GPUs.

SDXLLoRADiffusion
Systems

Socio Post Generator

PostGen: a few-shot post generator. It reads existing posts, extracts their style, tags and language, then asks an LLM to write new ones in the same voice.

Few-shotGroq APIPython
Systems

PDF2Podcast

A document-to-audio pipeline: Llama-3.2-3B rewrites a dense PDF into a two-speaker dialogue — one explains, the other asks what you'd actually ask — rendered to audio with Kokoro TTS.
